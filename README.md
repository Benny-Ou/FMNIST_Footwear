**Abstract**

In this project, I want to use Fashion-MNIST’s footwear subset to train and classify sandals, sneakers, and boots, taking the outputs I will reuse them in a larger CNN trained on the UT Zappos50k dataset for a more fine-
grained shoe category. Rather than simply stacking layers, this will provide me with a more detailed analysis of the hidden layers in the model by using activation visualizations, ablations, and robustness testing. The 
project highlights both the strengths and limitations of using prior datasets, demonstrating how the subnetworks can be reused to improve downstream classification tasks in the fashion industry.
